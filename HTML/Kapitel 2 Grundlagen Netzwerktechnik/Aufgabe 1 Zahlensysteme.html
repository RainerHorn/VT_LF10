Zahlensysteme in der Netzwerktechnik

Lernziel: Sie verstehen die Grundlagen der Zahlensysteme (Dezimal, Binär, Hexadezimal) und können diese ineinander umwandeln. Sie erkennen die Bedeutung dieser Systeme für Netzwerke in der Veranstaltungstechnik und wenden das Wissen praxisnah an.

1. Einleitung

In der Veranstaltungstechnik arbeiten Sie zunehmend mit netzwerkfähigen Geräten wie Lichtpulten, Kameras, Audiointerfaces oder Medienservern. Diese Systeme kommunizieren über IP-basierte Netzwerke. Damit Sie diese Netzwerke verstehen und einrichten können, ist es notwendig, die zugrundeliegenden Zahlensysteme zu kennen.

Computer und Netzwerksysteme arbeiten binär. Jede IP-Adresse, MAC-Adresse oder Subnetzmaske ist letztlich eine Kette von Einsen und Nullen. Das Verständnis dieser Darstellung hilft Ihnen, Probleme zu erkennen, Geräte richtig zu konfigurieren und Netzwerke professionell aufzubauen.

2. Überblick über Zahlensysteme

2.1 Dezimalsystem

Das Dezimalsystem ist Ihnen aus dem Alltag vertraut. Es verwendet die Ziffern 0 bis 9. Jede Stelle hat eine Bedeutung basierend auf Potenzen von 10.

Beispiel: 583 = (5 × 100) + (8 × 10) + (3 × 1)

2.2 Binärsystem

Das Binärsystem nutzt nur die Ziffern 0 und 1. Es ist das Fundament digitaler Technik. Jede Stelle steht für eine Potenz von 2.

Beispiel: 11001010 = (1×128) + (1×64) + (0×32) + (0×16) + (1×8) + (0×4) + (1×2) + (0×1) = 202

2.3 Hexadezimalsystem

Das Hexadezimalsystem basiert auf 16 Ziffern (0-9, A-F). Es wird zur Darstellung von MAC-Adressen oder Farben in Software genutzt.

Beispiel: 1101 0110 → D6

3. Praxisbezug

IP-Adressen

Eine IP-Adresse wie 192.168.0.1 besteht aus 4 Dezimalzahlen, die jeweils 1 Byte (8 Bit) entsprechen. In binärer Form lautet sie:

11000000.10101000.00000000.00000001

MAC-Adressen

Diese werden in hexadezimaler Schreibweise angegeben, z. B. 00:1A:2B:FF:6C:90. Sie bestehen intern aus 48 Bit.

Subnetzmasken

Die Maske 255.255.255.0 lautet in binärer Form:

11111111.11111111.11111111.00000000

4. Umrechnungen Schritt für Schritt

Dezimal → Binär

Beispiel: 156 → 10011100

Binär → Dezimal

01100110 = 64 + 32 + 4 + 2 = 102

Binär → Hexadezimal

1101 1001 = D9

Aufgabe 1 – Umwandlungen

b) 10101000 (Binär) → Dezimal
c) 255 (Dezimal) → Hexadezimal
d) 7F (Hexadezimal) → Binär
Aufgabe 2 – IP-Adresse analysieren

a) Wandle jede der vier Zahlen in Binär um.
b) Wie viele Bit hat die gesamte Adresse?
c) Erklären Sie, warum ein Gerät im Netzwerk eine solche Adresse benötigt.
Aufgabe 3 – Netzwerktechnik in der Praxis
Sie richten ein Netzwerk für eine LED-Videowand und ein Lichtpult ein. Beide kommunizieren über Art-Net.
Lichtpult: IP-Adresse 2.0.0.1
Medienserver: IP-Adresse 2.0.0.2
a) Wandle beide IP-Adressen in binäre Darstellung um.
b) Liegen beide Geräte im gleichen Subnetz, wenn die Subnetzmaske 255.0.0.0 ist?
c) Warum ist es wichtig, dass beide im selben Netzsegment liegen?
