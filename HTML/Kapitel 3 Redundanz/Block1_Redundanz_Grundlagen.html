📚 Phase 1: Informieren - Was ist Redundanz? (15 Minuten)

Was bedeutet Redundanz?

Redundanz bezeichnet in der Netzwerktechnik das Vorhandensein von mehrfachen, parallelen Komponenten oder Verbindungen, die im Fehlerfall automatisch die Funktion übernehmen können. Das Ziel: Ausfallsicherheit und hohe Verfügbarkeit.

Einfaches vs. Redundantes Netzwerk

Arten von Redundanz in der Veranstaltungstechnik

Redundanzart Beschreibung Beispiel in der VT Verfügbarkeit
Geräte-Redundanz Doppelte Hardware-Komponenten Zwei Core-Switches für Hauptbühne 99,9%
Pfad-Redundanz Mehrere Netzwerkpfade zwischen Geräten Zwei Glasfaserstrecken FOH ↔ Bühne 99,95%
Link-Redundanz Mehrere physische Verbindungen Link Aggregation (LACP) für Streaming-Server 99,99%
Protokoll-Redundanz Automatische Umschaltung bei Ausfällen VRRP für Gateway-Redundanz 99,999%

🔧 Warum ist Redundanz in der Veranstaltungstechnik kritisch?

  • Live-Events: Keine Wiederholung möglich – ein Ausfall ist unwiederbringlich
  • Finanzielle Risiken: Ausfälle können Vertragsstrafen bis zu 100.000 € bedeuten
  • Reputationsschaden: Negative Presse verbreitet sich schnell
  • Komplexe Systeme: Moderne Shows nutzen DMX, ArtNet, Audio-Streaming, Video über IP
  • Sicherheitsrelevant: Notbeleuchtung und Evakuierungssysteme müssen funktionieren

⚖️ Phase 3: Entscheiden - Das richtige Redundanz-Protokoll wählen (10 Minuten)

Spanning Tree Protocol (STP) - Die Basis für Redundanz

🔧 Was ist STP und warum brauchen wir es?

Problem: Wenn in einem Netzwerk redundante Verbindungen existieren, entstehen Schleifen (Loops). Diese führen zu Broadcast-Stürmen, die das gesamte Netzwerk lahmlegen.

Lösung: Das Spanning Tree Protocol (IEEE 802.1D) verhindert Schleifen, indem es:

  • Automatisch redundante Pfade blockiert (logisch deaktiviert)
  • Einen schleifenfreien Baum aus dem Netzwerk erstellt
  • Bei Ausfällen automatisch blockierte Pfade aktiviert

STP in Aktion: Schleifenvermeidung

STP-Varianten im Vergleich

Protokoll Standard Konvergenzzeit Verwendung in VT Vorteile
STP
(Spanning Tree)		 IEEE 802.1D 30-50 Sekunden ❌ Zu langsam für Live-Events Einfach, universell
RSTP
(Rapid STP)		 IEEE 802.1w < 3 Sekunden ✅ Standard für VT-Netzwerke Schnelle Umschaltung, abwärtskompatibel
MSTP
(Multiple STP)		 IEEE 802.1s < 3 Sekunden ✅ Für große Installationen mit VLANs VLAN-übergreifend, effizient
PVST+
(Per-VLAN STP)		 Cisco-proprietär < 5 Sekunden ✅ Bei reinen Cisco-Umgebungen VLAN-spezifische Optimierung

⚙️ Phase 4: Ausführen - RSTP konfigurieren (15 Minuten)

Grundkonfiguration von RSTP auf einem Switch

🔧 RSTP-Konfiguration Schritt für Schritt

Szenario: Core-Switch in einem Festival-Netzwerk konfigurieren

Schritt 1: Spanning Tree Modus auf RSTP setzen

! Wechsel in den Konfigurations-Modus
Switch> enable
Switch# configure terminal

! RSTP global aktivieren
Switch(config)# spanning-tree mode rapid-pvst

! VLAN für RSTP aktivieren
Switch(config)# spanning-tree vlan 1-100

Schritt 2: Root Bridge festlegen (Core-Switch als Haupt-Bridge)

! Priorität setzen (niedrigere Zahl = höhere Priorität)
! Standard: 32768, Root Bridge sollte 0-8192 haben
Switch(config)# spanning-tree vlan 1-100 priority 4096

! Alternative: Root Bridge automatisch setzen
Switch(config)# spanning-tree vlan 1-100 root primary

Schritt 3: PortFast für Access-Ports (Endgeräte)

! PortFast beschleunigt Endgeräte-Verbindungen
! ACHTUNG: Nur für Ports mit Endgeräten, NICHT zwischen Switches!
Switch(config)# interface range GigabitEthernet1/0/1-24
Switch(config-if-range)# spanning-tree portfast

! BPDU Guard aktivieren (Schutz vor versehentlichen Switch-Anschlüssen)
Switch(config-if-range)# spanning-tree bpduguard enable

Schritt 4: Link-Kosten anpassen (Priorisierung)

! Uplink zur Root Bridge bevorzugen (niedrigere Kosten)
Switch(config)# interface TenGigabitEthernet1/0/1
Switch(config-if)# spanning-tree vlan 1-100 cost 10

! Backup-Link höhere Kosten geben
Switch(config)# interface TenGigabitEthernet1/0/2
Switch(config-if)# spanning-tree vlan 1-100 cost 20

Schritt 5: Konfiguration überprüfen

! Spanning Tree Status anzeigen
Switch# show spanning-tree

! RSTP-spezifische Informationen
Switch# show spanning-tree summary

! Einzelnen Port prüfen
Switch# show spanning-tree interface GigabitEthernet1/0/1
