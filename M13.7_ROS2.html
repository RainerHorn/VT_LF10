Installation von ROS2 Humble auf Ubuntu 22.04

Diese Anleitung führt Sie durch die Installation von ROS2 Humble Hawksbill auf Ubuntu 22.04. Dies gilt sowohl für eine native Ubuntu-Installation, alle VM-Lösungen und auch für WSL (Windows Subsystem for Linux).

Voraussetzungen

  • Ein installiertes Ubuntu 22.04 System (nativ oder unter WSL 2).
  • Grundlegende Kenntnisse im Umgang mit der Kommandozeile.
  • Eine funktionierende Internetverbindung.

Schritt 1: Systemupdates durchführen

Bevor Sie ROS2 installieren, aktualisieren Sie Ihr System:

sudo apt update && sudo apt upgrade -y

Schritt 2: ROS2-Paketquellen hinzufügen

Fügen Sie die ROS2-Paketquellen zu Ihrem System hinzu:

  1. Installieren Sie zunächst notwendige Abhängigkeiten:
    sudo apt install software-properties-common
  2. Fügen Sie den ROS2-Repository-Schlüssel hinzu:
    sudo apt update && sudo apt install curl -y
    sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.asc | sudo apt-key add -
  3. Fügen Sie die ROS2-Repository-Quelle hinzu:
    sudo sh -c 'echo "deb [arch=amd64] http://packages.ros.org/ros2/ubuntu $(lsb_release -cs) main" > /etc/apt/sources.list.d/ros2-latest.list'

Schritt 3: ROS2 Humble installieren

  1. Aktualisieren Sie die Paketquellen:
    sudo apt update
  2. Installieren Sie ROS2 Humble und einige grundlegende Tools:
    sudo apt install ros-humble-desktop
  3. Entwicklerwerkzeuge und ROS-Pakete:
    sudo apt install ros-dev-tools

Schritt 4: ROS2 Umgebung einrichten

Um die ROS2-Umgebung bei jedem Start automatisch zu laden, fügen Sie den folgenden Befehl zu Ihrer ~/.bashrc hinzu:

echo 'source /opt/ros/humble/setup.bash' >> ~/.bashrc

Führen Sie den Befehl anschließend aus:

source ~/.bashrc

Schritt 5: Testen der Installation

Stellen Sie sicher, dass die Installation erfolgreich war, indem Sie ROS2 testen:

  1. Öffnen Sie ein neues Terminal und starten Sie einen ROS2-Knoten:
    ros2 run demo_nodes_cpp talker
  2. Öffnen Sie ein weiteres Terminal und starten Sie einen Listener, um die Nachrichten des Talkers zu empfangen:
    ros2 run demo_nodes_cpp listener
  3. Wenn beide Terminals Nachrichten austauschen, ist die Installation erfolgreich.

Zusätzliche Konfigurationen

  • Colcon-Build-Tool installieren: Wenn Sie eigene ROS2-Pakete entwickeln möchten, installieren Sie Colcon:
    sudo apt install python3-colcon-common-extensions
